# Deep Dive Example: SQLite vs DuckDB

A complete, real research run bundle produced with this skill's own protocol. Unlike `examples/minimal` (a synthetic fixture), this run:

- uses **three real official documentation pages** as sources (sqlite.org ×2, duckdb.org ×1);
- records a real clarification round and a confirmed `research_spec.yaml` (`depth: standard`);
- binds 7 located quotes to 4 claims, one of which is deliberately **`insufficient`** — the documentation alone cannot decide the boundary, and the bundle says so instead of guessing;
- carries a `verification.jsonl` generated by `scripts/verify_evidence.py`, which re-fetched every source and re-located every quote on the live page (**7/7 verified**, with `content_sha256` snapshots).

## Reproduce

```bash
# structural + verification gates (verification re-checked offline, no network)
python scripts/run_gates.py examples/deep-dive/run --require-final --require-verified

# re-verify against the live pages (network; appends a new pass to verification.jsonl)
python scripts/verify_evidence.py examples/deep-dive/run --timeout 30
```

Start the final report at `run/final_report.md`; the ledger (`sources/evidence/claims/conflicts`) is the ground truth it was derived from.
